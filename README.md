# Si on gratte un peu — Inhérente Compagnie

Site du spectacle. HTML/CSS/JS statique, sans outil de build.

- `index.html` : contenu
- `style.css` : mise en forme
- `script.js` : menu mobile et carte à gratter
- `images/` : photos (à ajouter)

Les éléments surlignés en jaune (« à confirmer », « à compléter ») sont à remplacer.

## Hébergement : Cloudflare Pages
Projet relié à ce dépôt. Réglages : Framework = None, Build command = (vide), Output directory = `/`.
Chaque modification poussée sur `main` met le site à jour automatiquement.
